# React + TypeScript + Vite

Getting Started✨

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Hotel-Booking-App.git
   ``


   npm install
   ``


 npm run dev
   ``


Features🤍

- Hotel reservation through:
  - Main hotel list
  - Filtered results
  - Hotel details section
- Filter hotels by entering:
  - Destination name
  - Length of stay
  - Number of guests (adults and children)
  - Number of rooms
- Interactive map built with **React Leaflet**
- Display user’s current location on the map
- User registration and authentication via login/register forms
- Protected routes to secure user-only pages
- Calendar for selecting date range using **Date Range** package
- Server-side error handling and displaying errors on the client side
- Redirecting users to their desired page after successful authentication


Packages📦

This project uses the following main packages:

- **React** – For building the user interface
- **TypeScript** – For type safety and better development experience
- **React Hook Form** – For form handling and validation
- **React Router DOM** – For client-side routing and protected routes
- **React Leaflet** – For interactive maps
- **Axios** – For making API requests
- **Date Range Picker** – For selecting check-in and check-out dates
- **JSON Server** – As a mock backend during development



Web Development Technologies🪄

The project is built using modern web development tools and technologies:

- **HTML5** – For structuring content and layout
- **Flexbox & CSS Grid** – For responsive and flexible layouts
- **React.js** – JavaScript library for building user interfaces
- **React Router DOM (RRD)** – For managing routing and navigation
- **Vite** – A fast build tool and development server for modern web projects
