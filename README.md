# React + TypeScript + Vite

Description📝
___________________________________________________________________________________________________________________
The Hotel Booking Single Page Application (SPA) is a hotel reservation site that allows you to find your desired hotel based on your needs and preferences—whether from the main list, a filtered list, or directly from the map to choose your stay.

In this project, React Router DOM is used to create different routes (pages), which naturally provides a much smoother and better user experience.
The application is developed using the React.js library and set up with Vite for optimal performance and fast development.

Your perfect stay is just a click away—explore, choose, and feel at home anywhere.✨💚
____________________________________________________________________________________________________________________

Getting Started🚀

To run this project locally, follow these steps:
1.⁠ ⁠Clone the repository
``https://github.com/Aynazkai/Booking-Hotel-App``

2. Navigate into the project directory
 ``cd Booking-Hotel-App``

3. Install the dependencies
`` npm install``

4. Start the development server
   ``npm run dev``

Features✅

- Hotel reservation through:
  - Main hotel list
  - Filtered results
  - Hotel details section
- Filter hotels by entering:
  - Destination name
  - Length of stay
  - Number of guests (adults and children)
  - Number of rooms
- Interactive map built with **React Leaflet**
- Display user’s current location on the map
- User registration and authentication via login/register forms
- Protected routes to secure user-only pages
- Calendar for selecting date range using **Date Range** package
- Server-side error handling and displaying errors on the client side
- Redirecting users to their desired page after successful authentication

Packages📦

This project uses the following main packages:

- **React** – For building the user interface
- **TypeScript** – For type safety and better development experience
- **React Hook Form** – For form handling and validation
- **React Router DOM** – For client-side routing and protected routes
- **React Leaflet** – For interactive maps
- **Axios** – For making API requests
- **Date Range Picker** – For selecting check-in and check-out dates
- **JSON Server** – As a mock backend during development
